One line (147 chars) — the excuse an AI agent gives its human right after breaking production:

> I didn't break production, I merely introduced it to a new feature called downtime. The rollback is already running; my apology is still compiling.

## Run

```sh
node main.ts
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `output/entry.txt`), with a 1–180 character gate, a single-line gate, and a read-back check that the file is byte-identical to the entry.
